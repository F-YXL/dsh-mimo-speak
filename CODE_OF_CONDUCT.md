# Code of conduct

## The short version

Be decent. Assume the other person is acting in good faith until they prove otherwise.
Criticise code, not people.

## Expected behaviour

- Keep technical disagreement about the code, the design, or the evidence — never about
  the person writing it.
- Accept that "this does not work" is a useful review comment, and say *why* when you
  reject something.
- Respect that this is a volunteer project: nobody owes you a fix, a review, or a release.

## Unacceptable behaviour

- Harassment, insults, personal or political attacks, or sustained disruption in issues,
  pull requests, or any project space.
- Publishing someone's private information (real name, employer, address, e-mail,
  hostname) without explicit permission. This includes pasting logs that contain it.
- Sexualised language or imagery, and unwelcome attention of any kind.

## Scope

This applies in issues, pull requests, commit messages, and any space where someone is
representing the project.

## Enforcement

Report a problem to the maintainer through GitHub (a private security advisory works if
you prefer a private channel: see [SECURITY.md](./SECURITY.md)). Reports are handled
confidentially. Responses scale with the behaviour: a clarifying question, a request to
edit or delete, a temporary block, or a permanent ban from the project spaces.

This document is adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, trimmed to the parts that actually apply to a single-maintainer plugin.
